## Docker access

Run `python deploy/scripts/docker_preflight.py` from the repository. A successful result reports Linux engine, current context and engine memory only. It never launches/restarts Desktop or switches context.

- `ENGINE_ACCESS_DENIED`: the invoking process lacks pipe/socket permission. Use authorized host execution; restarting Desktop does not fix process permissions.
- `BACKEND_NOT_READY`: Desktop reports running but the engine is unreachable. Inspect Desktop backend/context; optionally use `--wait-seconds 60` during startup.
- `ENGINE_UNREACHABLE`: inspect status/context; an absent pipe alone does not prove Desktop is stopped.
- `WRONG_ENGINE`: a Linux engine is required; select it explicitly outside this script.

Do not use repeated `Start-Process` calls to diagnose engine access. The user's existing running Desktop is preferred. No Windows/WSL service restart, context mutation or other-project container cleanup is performed.
