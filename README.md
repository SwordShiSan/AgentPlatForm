## 工程布局
frontend 为 Vue3/TypeScript；backend 为 Java21 六模块 DDD；contracts 为未来唯一机器契约；openspec 为规格与变更记录；deploy 为未来容器构建和部署。各目录 README 描述后续 R0 工作，不代表已实现。
先执行 R0 框架契约实验，门禁通过后进入 R1。不要运行不存在的 npm/mvn/compose 命令。
