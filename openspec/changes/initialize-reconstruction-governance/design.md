## Context

新仓只有目录骨架，正文由同级项目文档目录唯一维护。原阶段方案包含初始化状态表，若再建全局台账会双写。

## Goals / Non-Goals

目标：模块可执行细化、单一实施状态、分层证据、可核验Git交付。非目标：实现R0业务、部署、恢复后置事项或复制正文。

## Decisions

- 07只定义计划，08局部台账是唯一实施状态；全局只汇总，避免两套状态漂移。
- 90功能卡映射原40步骤，不另建90步串行路线。
- 本仓只记录治理规格和导航，不复制技术正文；克隆必须另附专项目录。
- SSH备用连接仅repo-local配置，严格校验官方主机key，不提交私钥或本机配置。

## Risks / Trade-offs

- 正文不在Git → 明确交接边界并登记文档丢失风险，不宣称推送包含正文。
- 框架方案尚未运行 → R0保留探针硬门禁，业务均NOT_STARTED。

## Migration Plan

迁移旧阶段状态表为08链接，保留实施范围。无需服务发布或数据迁移；文档回退保留单一状态源，不恢复双写。
