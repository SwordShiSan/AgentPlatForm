# Design
Reuse FileApplicationService, FileRepository, MyBatis/Spring, AMQP and runner fsync/rename/S3 sealing. Editor submits a frozen UTF8 File through create/transfer/complete and queries the original upload/operation after uncertainty. Revision ETag is not content SHA. Only CONFIRMED strict UTF8 <=2MiB is editable. Preserve BOM/newlines; no-op saves do not create versions. Monaco ESM workers are local lazy assets; mobile uses textarea. Drafts and pending snapshots are sessionStorage scoped by user/space/workspace/file, <=4MiB UTF8 total with explicit memory-only fallback. Query owns server metadata, local state owns dirty text. External changes never replace dirty buffers. Conflict compares base/current/local, explicit merge takes latest revision and new request ID. Save-as uses CREATE. No automatic unknown replay. A unified isolated launcher must freeze required services and readiness; max2887MiB, reserve768, single writer. Final observation180seconds, extend at most300 on actual trend. Reuse unchanged R4 XFS/gVisor evidence; no cloud window or repeated restore.
