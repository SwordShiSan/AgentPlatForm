# Design
## Decisions
Baseline9412d2c; MyBatis4/Boot4.0.8/SDK2.0.4, Reactor3.8.7. Domain remains pure Java. SnapshotQueryService and EventStreamService coordinate repository reads/stream lifecycle; EventRetentionService uses Spring scheduling. EventMapper/PO in infrastructure and XML in app; shared Spring transactions and DataSource(max4/min1).
Snapshot and each replay page use REPEATABLE READ including authorization/bounds/events; never hold DB transactions over network writes. V7 adds replay_pruned_through(0..next_seq), backfills deleted prefix from min existing seq or next_seq. Maintain event and projection atomic writes.
Cleanup fixed30days by DB time, continuous prefix only, at most1000 events/conversation and20 short transactions/minute, conversation FOR UPDATE SKIP LOCKED. Controlled SECURITY DEFINER fixed-search_path function has no arbitrary SQL/retention parameters; PUBLIC revoked, API EXECUTE only, worker denied. Preserve messages/tasks/ledger/checkpoints/budgets/outbox/inbox. Disable cleanup for rollback; old R2.C image remains compatible with additive schema.
The collector selects at most20 distinct candidate IDs; `pf.collect_expired_replay(uuid)` only narrows the candidate identity, never the policy. A separate managed maintenance scheduler keeps cleanup off the outbox scheduler. Runtime roles cannot directly update the watermark or delete replay rows. Existing authorization takes shared locks, so RR query transactions deliberately omit PostgreSQL's read-only flag.
MVC Flux<ServerSentEvent<EventView>> uses native SseEmitter adaptation, not WebFlux. Admission8, writer4/8 queue0, DB executor2 queue16, poll250ms, heartbeat2s, lifetime25s, servlet deadline30s, Tomcat NIO timeout10s, gateway read40s/send10s. Explicit Reactor demand/prefetch1; per-stream256 events/1MiB max. Preflight auth/cursor/admission errors before200; post-start failures close. Separate periodic authorization even when downstream demand stalls. Browser disconnect never cancels task. Minimum lifecycle PoC must pass before wiring production streaming.
Fetch+AbortController+eventsource-parser4.1.2(MIT, Node>=22.12) and existing Ajv standalone(no eval). Actor/space/conversation/generation guard all late results. Only successfully applied seq advances; repeats discarded; gap/offset/410/409 rebase once;401 clears identity,403/404 stop,503/network backoff1/2/4/8/15s+jitter. Offline pauses. Parser bounded conservatively262144 characters plus application byte accounting<=1MiB. Structural-sharing reducer. No automatic model request/retry.
## Interfaces
Existing snapshot/events shape and platform_event v1 stay. after wins over Last-Event-ID; default0. Malformed/overflow/unsafe integer400; negative/ahead409; after<prunedThrough410. Same cursor at watermark valid. Unknown/bad frames cannot advance cursor or leak data. New internal typed EventPage includes bounds/rows only; no new public endpoint or UI capability.
## Migration / Rollback
Add V7 only; runtime baseline remains1. Use isolatedagentplatform-r22-local, ports15445/15685/15695/18090 with preflight conflict rejection; max2528MiB initial/2887 cap and768 host reserve. Build/runtime serial, single execution/hash slot. Disable collector and use prior R2.C image; do not reverse schema or recreate deleted events. Snapshot repairs expired replay.
