# Design
Approved 2026-10-16 at ee741e3. API/app owns transactions and authentication; domain pure ports/rules; infrastructure JDBC/AMQP/AgentScope/crypto; trigger HTTP/SSE. Runtime and API profiles are explicitly local opt-in. Existing R0 production remains untouched.

V3 adds composite tenant FKs, conversation sequence, immutable task config snapshot, global execution slot, dispatch generation/fence/60s lease, calls, reservations and credential audit. Submission transaction records user/assistant projections, task, budget and outbox/idempotency response. Same key/body returns original result; different body conflicts. Queue accepts up to 20 queued tasks per actor, global pending cap10000/15min oldest. Outbox poll500ms, publish lease30s, mandatory confirms, exponential retry and review after10 failures. Persistent quorum ap.execution.v1 in /agentplatform; worker prefetch1. Commit claim/attempt/inbox before ACK. No DB execution fallback.

Live deltas commit every100ms or4KiB, bounded to configured output/context limits; platform event and projection update atomically. SSE reads committed events with seq/codepoint offsets and per-request authorization, repeatable-read snapshot watermark, 2s heartbeat and bounded buffers256/1MiB. A maximum8 SSE workers use direct handoff with no waiting queue; excess connections return retryable503. Short heartbeats reclaim disconnected streams promptly instead of leaving new streams queued behind25s requests. Disconnect never cancels work. Unknown schema goes to quarantine. Old fences cannot update or begin calls. Stale started call => UNKNOWN/reservation RECONCILING, never replay; operator confirms old owner stopped before releasing slot/failing interrupted tasks. Full R2 recovery is not claimed.

HC-1 adds asynchronous delta callback plus cancellation-compatible stream default for old complete-only probes; SDK/Reactor stay infrastructure. BridgeModel streams real OpenAIChatModel responses, no hidden reasoning propagation. Remove collectList of SDK events. Each attempt owns its instance/resources. No tools and no Plan. Context is canonical USER/ASSISTANT history plus fixed server system text; no UI/control messages. Runtime window8192, maxOutput1024, safety1024; required context overflow blocks without silent deletion. Estimation is explicit.

Model deepseek-flash at fixed https://api.deepseek.com/chat/completions, thinking disabled, stream and usage enabled. No arbitrary endpoints/redirects or TLS bypass. Operator imports user-provided key via private file to per-space AES256GCM (random nonce, AAD space/id); independent secret master key mounted only to operator/trusted worker. API has no key/master. Provider exception allows attempt-scoped worker decryption; audit credential/call IDs only. No actual key in command args/build/log/checkpoint/evidence. Pricing snapshot sourced from official2026-10-16 docs, peak cache-miss bound for reservation, actual token usage distinguished from estimated cost/unknown usage.

At most4 physical calls/task, pre-output retries at most2 (1s/3s), one empty-response repair, shared120s deadline. Output then failure is partial, no transparent retry. Each physical call unique; preallocated task budget partitioned per call, no double reserve. Missing usage remains reconciling rather than zero. Real acceptance cap20 physical calls and1 CNY, durable cap across restarts.

Initial API384/worker640/PG320/MQ256/Redis64/gateway32 MiB (1696). Optional S3 only for relevant regression; runner/egress/sandbox off. Module allocations may change with evidence; total container limits <=3655-768=2887MiB, one execution/hash slot, no swap-backed expansion. No build during constrained acceptance. Local independent databases/ports/credentials/projects only. Rollback disables chat and preserves additive data.

## 2026-10-16 user steering: database platform and user credentials
Credential records distinguish scope_type PLATFORM/USER. PLATFORM has null owner_user_id/space_id and is governed by platform policy; USER requires owner_user_id and space_id plus real membership/ownership validation. Store ciphertext/nonce/tag/key_version/status/revision only, never plaintext. AES-GCM AAD binds scope_type,id,owner and space (explicit platform sentinel). Master key remains external. Frozen task config resolves an authorized server-side credential binding and source policy; no raw credential selector from browser and no silent platform/user fallback. This step imports the supplied test key as PLATFORM; USER schema, repository authorization and crypto isolation are mandatory tests, user-facing management remains later.

Runtime roles receive no identity-table mutation or credential-ciphertext access for API. PostgreSQL row locks require UPDATE privileges, so two narrow SECURITY DEFINER authorization functions hold the current actor/credential share locks without granting identity mutation to callers. Functions pin search_path, accept typed UUID/revision inputs, return boolean only, and revoke PUBLIC execute; the fixture explicitly grants only the required runtime roles. Binding resolution is a frozen read, with credential scope/revision/status rechecked before each call. Unknown transport outcomes never retry; only explicit pre-output429/5xx rejection may use the bounded retry policy.

The composition validator explicitly admits the frozen DeepSeek text-stream bundle alongside the historical scripted bundle, rejecting unknown component/model combinations. The same bundle/hash is persisted and passed to Harness. SDK unversioned private-state save is adapted by reading the current slot version and performing exact CAS; no negative-version write sentinel or blind overwrite is sent to PostgreSQL. Conflicts fail the attempt rather than overwriting newer state.

Resource measurements found API384MiB cgroup OOM; redistribute API/worker to512/512MiB (heap224/256MiB), preserving1696MiB resident total. Use a shared bounded4-connection HikariCP pool per chat runtime for identity/chat/private state to avoid repeated SCRAM handshakes during SSE polling; the Boot BOM manages its version. Operator/legacy constructors remain available for isolated probes. Pool acquisition is bounded and fails closed. SSE flushes an initial comment before polling so disconnects/headers are promptly observed. All findings and prior failures remain evidence; revised limits require reacceptance.

SDK GenerateOptions explicitly uses ExecutionConfig maxAttempts=1 and retryOn=false. Platform call ledger alone owns retries; HTTP fixture counters must equal ledger rows for429/5xx/unknown transport. Worker profile suppresses SDK diagnostics that can include untrusted raw provider error bodies; platform logs retain sanitized reason codes. Docker build explicitly packages current sources before COPY, preventing a new image from silently embedding an older implementation. Reproducible jar timestamps cannot serve as a freshness check.
