## Transactions and effects
Reserve space bytes and freeze upload metadata before content. Stream private staging with exact size/hash. complete atomically emits outbox; correlated confirm then durable claim/MANUAL ACK precede runner effects. Lock order: space_storage -> existing capacity/auxiliary slots -> workspace -> operation/command/receipt; no network wait in DB transactions. Permissions and fence rechecked before effects and projection commit.
Runner obtains immutable staging with narrowly configured S3 client, streams via Docker exec stdin to fixed helper; helper has no network/S3 credentials/socket and mounts only work. Filesystem write is temp + fsync + atomic rename + parent fsync with original operation receipt. Replacement rechecks physical hash and expected version under write lease. Immutable version object must verify before projection success. Missing mount/link/hardlink/special files fail closed.
UNKNOWN uses original command query only, no lease-expiry release, blind retry or double accounting. Lease60s/renew10s preserved; positive stop evidence required.24h staging expiry excludes active or unknown effects. No destructive GC/history removal in this stage.

## UI
Browser incremental SHA256 uses pinned official @noble/hashes2.4.0 (MIT), sha256.create().update().digest(), chunked File reads. No custom hash implementation, full-file ArrayBuffer, WebAssembly CSP relaxation, or persistent file bytes. HTTP single-range parsing delegates to Spring HttpRange; product policy restricts one range.
Vue Query owns durable metadata and operations; browser-local selected File is not persisted or put in Pinia. Show explicit replacement, retained selection on412, original operation recovery after response loss, safe text preview, no inline HTML. No edit/move/delete/restore/shell buttons.
